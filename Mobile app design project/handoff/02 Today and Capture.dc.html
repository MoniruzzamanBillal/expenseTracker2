Screen 2 · app/(tabs)/addTransaction.tsx

Add entry

Amount first, typed on an in-app keypad in the thumb zone, so the most common entry (amount + category) never raises the system keyboard. Title and note use the system keyboard only when tapped.

Save POST /transactions/new-transaction {type, amount, title, description?, categoryId?}. If a receipt is attached: then PUT /transactions/receipt-file/:id (multipart "file") with the returned _id.
Categories GET /categories → chip row; first chip "None" sends categoryId null.
Keypad Flex rows of Pressables, same regex as today (/^\d+(\.\d{0,2})?$/) — invalid keys simply don't register, so the "Invalid Amount" toast goes away.
Title Required by the API; if empty on save we fall back to the category name instead of blocking — see A4 for the validation that remains.
Diverged "Requests" button moved to Today's inbox icon. Smart Add stays here as the one header action. Offline: unchanged queue behaviour, the button reads "Save offline".

Pick → chip (A4) → view → remove. The server only accepts a file on an existing transaction, so on Add the file rides along as a chip and uploads right after create.

Upload PUT /transactions/receipt-file/:id, field "file", image or PDF, 10 MB cap (multer). A second upload replaces the first.
Display receiptFileUrl, receiptFileOriginalName for the chip, receiptFileResourceType "image" | "raw" chooses image vs PDF viewer.

Screen 3 · app/(tabs)/smart-add.tsx

Smart Add

Write a sentence, get drafts, fix what's wrong, save once. The review list is the screen — each draft is a card you can edit in place or discard; nothing is written until the one Save.

Parse POST /transactions/manage-money {prompt} → data: [{type, amount, title, description}] (no category — the AI never returns one).
Save POST /transactions/many-transaction with the edited array + categoryId per draft (spec 22 picker). Response is Prisma's {count} — S4 uses that count.
Empty data: [] → "Didn't find any amounts in that" with the text kept for editing.
Error 400 "AI returned invalid transaction data" or OpenRouter failure → S5, text preserved.
Diverged Drafts without a category are flagged "No category" rather than silently saved as Uncategorized.

Screen 11 · app/quick-add.tsx + widgets/QuickAddWidget.tsx

Quick Add + widget

A sheet over a scrim, not a screen: no tab bar, no header, one job. The deep-link type presets the toggle; the keypad and Save sit in the thumb zone. On save it closes back to the launcher.

Entry client://quick-add?type=expense|income → toggle preset, keypad focused.
Save same POST /transactions/new-transaction; offline queue applies. No receipt here (that's what the full Add is for).
Widget FlexWidget + TextWidget only: flat rects, 1px borders, 16/12 radii, hardcoded palette below (the widget can't read ThemeContext). No data shown — it runs in a headless task without the auth token flow, so a total would be stale or wrong.
