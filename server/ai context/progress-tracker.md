## Current state

Core API surface is built and working: auth (register/login + `GET /me`/`PATCH /update-profile`), transaction CRUD (now with an optional `categoryId`), per-user categories (CRUD), per-category budgets (CRUD, informational only, no enforcement), four report endpoints (daily/monthly/yearly/weekly, three of which now carry a `categoryBreakdown`), and AI-assisted bulk transaction parsing. There is no active multi-phase build plan — this is a maintained, already-shipped personal project, not greenfield work. The `specs/` scaffolding below exists for the _next_ piece of nontrivial work, not a backlog of already-completed phases.
